# quipu Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `quipu`, a Go CLI + TUI that tracks git worktrees in bare-layout containers, mines Claude Code data files to recover each worktree's purpose/state, stores everything in SQLite, and restarts Claude sessions in WezTerm.

**Architecture:** Small focused packages under `pkg/`, composed by `pkg/cli` and dispatched from `cmd/quipu`. A single exec seam (`pkg/execx.Runner`) makes every git/wezterm interaction fake-able in tests. `pkg/scan` is the only writer that merges discovered facts into `pkg/store`.

**Tech Stack:** Go 1.26, `modernc.org/sqlite` (pure Go), `charmbracelet/bubbletea|lipgloss|bubbles` (TUI only), everything else stdlib. stdlib `flag` subcommand dispatch (no cobra).

**Spec:** `docs/superpowers/specs/2026-08-27-quipu-design.md` — read it first; the data model, classifier precedence, CLI surface, and error-handling rules there are normative. Reference implementations to imitate (read-only): `~/src/reclaude` (Runner seam, wezterm client, slug), `~/src/git.fish/functions/_git_worktree_status.fish` (classifier), `~/src/git.fish/functions/_git_wclean_config.fish` (defaults: protected branches `main master develop trunk`, stale-days 30), `~/src/git.fish/functions/git-wlist.fish` (state sort order, line ~150: `merged pr-closed gone stale error detached active protected`; quipu appends `missing` last).

Every task follows the same TDD discipline even where not restated: write the failing test, run it and see it fail, implement minimally, run it and see it pass, then commit.

**Conventions (user's global CLAUDE.md):** conventional commits; no self-credit in commits; 4-space indent where not gofmt-controlled; functional style over classes; Go 1.26 idioms (`any`, generics, `strings.SplitSeq`, `for range N`).

Each task below is TDD: failing test → verify fail → minimal impl → verify pass → commit. Run tests with `go test ./pkg/<pkg>/ -run <Name> -v`. Every commit must leave `go build ./... && go vet ./...` clean.

### Task 5: lifecycle classifier

Port `_git_worktree_status.fish` exactly. `Classify(ctx, r execx.Runner, w WorktreeInfo, integration string, staleDays int, protected []string, forge bool) Status` where `Status{State, Branch, Upstream, Dirty bool, AgeDays int}`. Callers pass the hardcoded v1 defaults `protected = ["main","master","develop","trunk"]` and `staleDays = 30` (from `_git_wclean_config.fish`; no config file/flag in v1 — export them as `gitx.DefaultProtected`/`gitx.DefaultStaleDays`).

Precedence (first match): protected → detached → merged (`git rev-list <head> --not <integration>` empty **and** exit 0) → pr-closed (only if forge: `gh pr view <branch> --json state --jq .state` cwd=worktree, MERGED/CLOSED) → gone (`for-each-ref %(upstream:track)` == `[gone]`) → stale (age>staleDays) → active. Dirty = `git status --porcelain` non-empty **or the command failed**. Age = `(now - git log -1 --format=%ct) / 86400` floor. Any unresolvable worktree ⇒ `State: "error"` (callers keep-and-report, never guess). No fetch inside Classify.

- [ ] **Step 1:** Failing table-driven tests with FakeRunner covering every state + precedence collisions (merged beats gone; protected beats merged; dirty-on-status-failure fail-safe; error on rev-parse failure).
- [ ] **Step 2:** Implement `status.go`. Integration-branch helper `IntegrationBranch(ctx, r, worktree)`: `git symbolic-ref refs/remotes/origin/HEAD --short` → `origin/main` error message guidance per git.fish (`git remote set-head origin --auto`).
- [ ] **Step 3:** Pass; commit `feat: port worktree lifecycle classifier to gitx`.

## Chunk 4: scan engine + core CLI

### Task 9: pkg/scan

`Scan(ctx, deps, opts)` — deps: store, execx.Runner, home, now; opts: {Container string, Worktree string, Fetch, Forge bool}.

Pipeline per spec: optional `git fetch --prune origin` (60s timeout, failure = warning not error) → enumerate worktrees → classify each → upsert → mark missing rows → per worktree: list `<projectDir>/*.jsonl` (top-level only), skip unchanged (size+mtime), ScanSession, upsert session facts; index-fallback rows for pruned jsonls (`jsonl_exists=0`); import claude task files (`external_key = "tasks/<sid>/<n>.json"` — the path relative to `~/.claude`, per spec; source=imported, pending→open/in_progress→in_progress/completed→done); live registry → set live_pid (clear stale first); purpose inference (ai-title → index summary → first prompt) only when purpose_source != manual; insert `scan` event on state change except gone↔pr-closed; update jsonl_size/mtime + last_scanned. The 60s fetch timeout is a plan-author decision (spec just says "with a timeout"). Classification failure of one worktree records `state=error` and continues — it must never abort the rest of the scan.
